# Artifact templates

One markdown template per harness artifact, in the same style as [prod_business_requirement_document.md](prod_business_requirement_document.md):

- `<h2 id="*_details" data-label="…">` marks a prose section.
- `<div id="*_table" data-label="…" data-columns="…">` marks a table with fixed columns.
- `<div id="*_block" data-format="…" data-src="…">` marks a code block that holds or mirrors the machine-readable definition (JSON, YAML, GraphQL SDL, Avro, SQL, Gherkin, Mermaid).

The YAML frontmatter records the artifact, work item, version, status, document and definition paths, producing skill, inputs, reviewers and the event it emits. `{wi}` is replaced by the work item ID.

These files are generated by `harness-engineering.html` (Orchestration → ⤓ Scaffold .sh writes them to `templates/artifacts/`). Edit an artifact's sections in the playbook (✎ Edit artifact → Template), not here. Check a filled document with `node scripts/harness-template-check.mjs <doc> templates/artifacts/<ID>.md`.
